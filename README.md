# Corne 36-key Layout

VIA config for Corne 36-key keyboard with Swedish OS layout.

OS keyboard layout: **Swedish**. All keycodes are interpreted under the Swedish OS layout.

---

```
┌─────┬─────┬─────┬─────┬─────┐         ┌─────┬─────┬─────┬─────┬─────┐
│  Q  │  W  │  E  │  R  │  T  │         │  Y  │  U  │  I  │  O  │  P  │
├─────┼─────┼─────┼─────┼─────┤         ├─────┼─────┼─────┼─────┼─────┤
│  A  │  S  │  D  │  F  │  G  │         │  H  │  J  │  K  │  L  │  ö  │
├─────┼─────┼─────┼─────┼─────┤         ├─────┼─────┼─────┼─────┼─────┤
```

## Layer 1 — Navigation / Swedish / Numbers (hold left inner thumb)

```
┌─────┬─────┬─────┬─────┬─────┐         ┌─────┬─────┬─────┬─────┬─────┐
│  1  │  2  │  3  │  4  │  5  │         │  6  │  7  │  8  │  9  │  0  │
├─────┼─────┼─────┼─────┼─────┤         ├─────┼─────┼─────┼─────┼─────┤
│ ESC │ TAB │     │     │     │         │  ←  │  ↓  │  ↑  │  →  │BSPC │
├─────┼─────┼─────┼─────┼─────┤         ├─────┼─────┼─────┼─────┼─────┤
│  å  │  ä  │  Å  │  Ä  │  ö  │         │HOME │PGDN │PGUP │ END │     │
└─────┴─────┴─────┴─────┴─────┘         └─────┴─────┴─────┴─────┴─────┘
                  ┌──────┬──────┬──────┐ ┌──────┬──────┬──────┐
                  │ MO13 │ TAB  │ SHFT │ │ ENT  │ GUI  │ MO23 │
                  └──────┴──────┴──────┘ └──────┴──────┴──────┘
```

i3 shortcuts:
- `Win+Enter` (open terminal): MO13 + GUI + ENT
- `Win+Shift+Number` (move to workspace): MO13 + SHFT + GUI + top row number
- `Win+Shift+Arrow` (move window): MO13 + SHFT + GUI + HJKL

## Layer 2 — Programming Symbols (hold right inner thumb)

```
┌─────┬─────┬─────┬─────┬─────┐         ┌─────┬─────┬─────┬─────┬─────┐
│  "  │  '  │  `  │  =  │  @  │         │  #  │  &  │  *  │  /  │  \  │
├─────┼─────┼─────┼─────┼─────┤         ├─────┼─────┼─────┼─────┼─────┤
│  1  │  2  │  3  │  4  │  5  │         │  6  │  7  │  8  │  9  │  0  │
├─────┼─────┼─────┼─────┼─────┤         ├─────┼─────┼─────┼─────┼─────┤
│  (  │  )  │  [  │  ]  │  {  │         │  }  │  <  │  >  │  |  │  _  │
└─────┴─────┴─────┴─────┴─────┘         └─────┴─────┴─────┴─────┴─────┘
                  ┌──────┬──────┬──────┐ ┌──────┬──────┬──────┐
                  │ MO13 │ GUI  │ SHFT │ │ CTRL │ RALT │ MO23 │
                  └──────┴──────┴──────┘ └──────┴──────┴──────┘
```

All AltGr-requiring symbols (`{`, `}`, `[`, `]`, `@`, `\`, `|`) are pre-encoded — no manual AltGr needed.
